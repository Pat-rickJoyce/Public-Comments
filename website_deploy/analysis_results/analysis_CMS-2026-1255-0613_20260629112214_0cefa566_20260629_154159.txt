## 2. EXECUTIVE SUMMARY

DataSpring supports the proposed extension of prior authorization requirements to drugs under both medical and pharmacy benefits, including decision timeframes, transparency, and API reporting. The comment encourages CMS to refine requirements over time toward greater uniformity, especially standardized decision-reason code reporting and measurement of API value and ROI.

## 3. REGULATORY CONTEXT

- **Specific provisions addressed:** PA-DRUG-MEDICAL; PA-DRUG-PHARMACY; PA-TIMEFRAMES-DRUGS; PA-DENIAL-REASONS; API-USAGE-METRICS; TRANSPARENCY; GENERAL.
- **Regulatory citations mentioned:** No CFR citations.
- **Standards referenced:** CMS-0057; API reporting; decision-reason code reporting; general interoperability standards.

## 4. DETAILED POSITIONS

**Topic 1: Extending PA requirements to drugs**
- **Provision ID:** PA-DRUG-MEDICAL; PA-DRUG-PHARMACY
- **Position:** Support
- **Rationale:** DataSpring believes expansion to medical and pharmacy benefit drugs will reduce variability, administrative burden, and delays in patient access.
- **Specific request:** Finalize the extension of CMS prior authorization requirements to drugs covered under both benefit types.

**Topic 2: Decision timeframes**
- **Provision ID:** PA-TIMEFRAMES-DRUGS
- **Position:** Support
- **Rationale:** The proposed standards and timeframes are described as appropriate and a thoughtful expansion of CMS-0057.
- **Specific request:** Maintain decision timeframe requirements and revisit refinement as implementations mature.

**Topic 3: Transparency and reporting**
- **Provision ID:** API-USAGE-METRICS; TRANSPARENCY
- **Position:** Support/Modify
- **Rationale:** Transparency can inform targeted refinement of PA strategies and reduce burden without undermining utilization management.
- **Specific request:** Use API reporting to evaluate policy impact, administrative efficiency, cycle times, burden reduction, and ROI.

**Topic 4: Standardized decision-reason codes**
- **Provision ID:** PA-DENIAL-REASONS
- **Position:** Modify
- **Rationale:** Variability and ambiguity in decision reasons can undermine the benefits of electronic workflows.
- **Specific request:** Further refine requirements through standardized approaches to decision-reason code reporting.

## 5. SOLICITATION RESPONSES

- **S16/S17:** Supports clearer and more standardized decision-reason code reporting to reduce ambiguity.
- **S20/S43:** Supports the proposed decision timeframes as appropriate for advancing rule goals.
- **S29/S34/S35:** Supports expanded API reporting as a way to evaluate interoperability strategies, ROI, administrative efficiency, cycle times, and burden reduction.
- **S12/S14/S21/S22:** Supports extension to drugs generally but does not provide detailed technical challenge responses.

## 6. RECOMMENDATIONS

1. Finalize extension of PA requirements to drugs under both medical and pharmacy benefits.
2. Maintain the proposed decision timeframes.
3. Enhance transparency and reporting requirements.
4. Refine decision-reason code reporting to improve uniformity and reduce ambiguity.
5. Use API reporting to measure value, ROI, cycle times, administrative efficiency, and burden reduction.
