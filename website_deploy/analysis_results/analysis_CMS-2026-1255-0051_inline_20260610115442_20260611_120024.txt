## 2. EXECUTIVE SUMMARY

The commenter opposes any prior authorization policy that requires authorization before blood can be drawn for genetic testing. He states that blood should be drawn during the same visit as counseling because requiring a separate return visit significantly delays testing and patients often do not return.

## 3. REGULATORY CONTEXT

- **Specific provisions addressed:** GENERAL/RFI.
- **Regulatory citations mentioned:** None.
- **Standards referenced:** None.

## 4. DETAILED POSITIONS

**Topic 1: Prior authorization before blood draw**
- **Provision ID:** GENERAL
- **Position:** Oppose
- **Rationale:** Requiring PA before blood is drawn delays genetic testing and disrupts efficient clinical workflow.
- **Specific request:** Do not require prior authorization before blood can be drawn for genetic testing.

**Topic 2: Same-visit specimen collection**
- **Provision ID:** GENERAL
- **Position:** Support
- **Rationale:** Drawing blood at the same visit as counseling avoids separate return visits, which patients may not complete.
- **Specific request:** Permit blood draw during the counseling visit even if authorization is not yet complete.

## 5. SOLICITATION RESPONSES

- **S66-S82:** The comment responds to the laboratory testing RFI by describing how PA before specimen collection affects genetic testing, patient follow-up, and provider workflow.

## 6. RECOMMENDATIONS

2. Allow same-visit blood draw when genetic counseling and test ordering occur.
3. Avoid PA workflows that require patients to return for a separate lab draw.
