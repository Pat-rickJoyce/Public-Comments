ORIGINAL COMMENT EXCERPT
------------------------
It is great to see a continuation of automation in prior authorization.  As a patient/caregiver, I would like to know about all of the prior authorization communication so that I can help and I can correct things if I notice an issue.  Also, if the authorization is denied, it would greatly reduce patient burden and stress as well as help providers if there was also a way to automate the appeal process.  Both the patient and provider should be able to electronically appeal and track status on the appeal request to the payor.  Thank you....
